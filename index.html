WEB FUNDAMENTALS

Explore the Web.

كيف يعمل الويب؟

المستخدم يطلب صفحة من خلال المتصفح، فيرسل المتصفح طلب HTTP إلى الخادم، ثم يستقبل الاستجابة ويعرض المحتوى.

H

HTML

HyperText Markup Language لغة ترميز تُستخدم لتنظيم هيكل الصفحة، مثل العناوين والفقرات والصور والأزرار.

<h1>Hello Web</h1>
C

CSS

Cascading Style Sheets تتحكم في تصميم الصفحة مثل الألوان والخطوط والمسافات وتوزيع العناصر.

h1 { color: purple; }
JS

JavaScript

لغة برمجة تضيف التفاعل إلى الموقع، مثل الاستجابة للنقرات وتحديث المحتوى وتنفيذ العمليات.

button.addEventListener("click", fn);
F

Frontend

الجزء الذي يراه المستخدم ويتفاعل معه داخل المتصفح، مثل التصميم والقوائم والنماذج.

B

Backend

الجزء الذي يعمل على الخادم ويعالج الطلبات ويتعامل مع البيانات وقواعد البيانات.
